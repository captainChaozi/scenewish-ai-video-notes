# SceneWish blog: three walkthroughs and which to read first

Source: [SceneWish Blog: Video Ideas & Guides](https://scenewish.com/blog) · Create: [SceneWish AI video](https://scenewish.com/)

The SceneWish blog currently has three walkthroughs. Each one starts from a recorded example and ends with a clip you check before sharing. They map to three different starting points.

| Start with… | Read | Then open |
|---|---|---|
| A photo and one simple movement | [Photo to Video: A Beginner's Guide to One Clear Movement](https://scenewish.com/blog/photo-to-video) (15 Oct) | [Image to Video](https://scenewish.com/image-to-video) |
| A portrait and a ready-made emotional effect | [How to Make an AI Crying Effect from One Photo](https://scenewish.com/blog/ai-crying-effect) (15 Oct) | [AI Crying template](https://scenewish.com/templates/ai-crying) |
| Only an idea, no media | [Build a Text to Video Prompt: Paper Ocean Walkthrough](https://scenewish.com/blog/text-to-video-prompt) (13 Oct) | [Text to Video](https://scenewish.com/text-to-video) |

## Suggested order for a first-timer

1. **Photo to Video** first. It teaches the core habit: one clear movement, a clean start image, review before download.
2. **AI Crying** next. A template removes the prompt-writing step, so you learn what the input photo needs.
3. **Paper Ocean** last. Writing a full scene prompt is the hardest of the three, and it is easier once you have judged a few results.

## The shared lesson

All three end the same way: change one thing at a time, watch the result, and check it before you share. That habit saves more credits than any single prompt trick.
