# Frame-pair comparison: one input, three models

A recorded comparison from SceneWish's [first and last frame to video](https://scenewish.com/first-last-frame-to-video) page. Same start frame, same end frame, same prompt.

**Prompt:** "Keep the camera and street fixed as daylight fades into blue-hour night."

| Model | Duration | Reached blue hour? |
|---|---|---|
| Seedance 2.0 Fast | 5 s | Yes |
| Kling v3 | 5 s | No, warm daylight remained |
| Veo 3.1 Fast | 8 s | Yes |

Takeaways

- Models follow transition prompts differently; one attempt is not a verdict on a model.
- Keep both frames from the same viewpoint so the model only has to change the light.
- If the change does not happen, try another model before rewriting the prompt.
