# SceneWish: submit once, then follow the task

Source: [SceneWish User Guide](https://scenewish.com/user-guide) · Home: [SceneWish](https://scenewish.com/) · Plans: [pricing](https://scenewish.com/pricing)

Generation time varies, and there is no guaranteed completion time. The most expensive mistake is submitting the same idea again while the first task is still running.

## Before pressing generate

Review the model, duration, aspect ratio, resolution, audio setting and credit quote. Uploading or preparing a draft is not a submission.

## After pressing generate

- An accepted task charges its quoted credits.
- If a request is pending, or its acceptance is being checked, **follow that task** instead of creating new ones.
- Refreshing the page or returning to the task is not a new submission. A **new submission can create a new chargeable task.**

## If something goes wrong

- A task confirmed as failed or canceled returns its charged credits.
- A task-credit return is separate from a cash refund.
- For a missing credit return or an unresolved task, note the **task ID** and contact support. Never send passwords or full card details.
