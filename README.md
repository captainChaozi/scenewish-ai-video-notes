# SceneWish AI video notes

Practical notes for making short AI videos with [SceneWish](https://scenewish.com/): AI video effect templates plus image-to-video, text-to-video and related workflows. The credit cost is shown before you generate.

## Choose a workflow
| You have / want | Use |
|---|---|
| A demonstrated effect you like | [Templates](https://scenewish.com/templates) (e.g. [AI crying](https://scenewish.com/templates/ai-crying), [finger heart](https://scenewish.com/templates/finger-heart), [cinematic orbit](https://scenewish.com/templates/cinematic-orbit), [pet pilot](https://scenewish.com/templates/pet-pilot)) |
| A photo + one movement | [Image to Video](https://scenewish.com/image-to-video) |
| A clip that must end on a specific frame | [First & Last Frame to Video](https://scenewish.com/first-last-frame-to-video) |
| An idea, no picture | [Text to Video](https://scenewish.com/text-to-video) |
| An existing clip to change | [Video to Video](https://scenewish.com/video-to-video), [Motion transfer](https://scenewish.com/motion-transfer), [Extend](https://scenewish.com/extend-video) |

## First-clip rules
1. One picture, one movement, one shot.
2. A readable face if the face should move; room in the frame for the action.
3. Use images you own or have permission to animate.
4. Change one thing per retry.
5. Check faces, hands and edges before downloading; generated frames do not preserve every pixel.
